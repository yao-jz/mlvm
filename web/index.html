Verifiable model execution

Verify how a model
produced its answer.

Suppose a service runs a model for you and returns an answer. The answer alone cannot show whether it used the model and input you agreed on. MLVM lets another computer repeat the run and compare what happened inside, even when the displayed words match. If the runs disagree, a separate checker can redo the disputed calculation without rerunning the whole model.

Independent checks

The checker can use a different computer.

One person can run the model on a Mac; another can check it on Linux, Windows or in a browser. For the built-in story model, we recorded matching runs across these systems with the same model and input.

Try it · Step 2 of 2

What if two runs disagree?

MLVM runs the same model again, but deliberately makes one calculation wrong. You can choose other mistakes below. The two runs may print the same words while holding different numbers inside.

If their identifying codes differ, MLVM finds where the runs first changed and checks what should have happened there. The default example takes about 26 comparisons to find one operation among 38 million.

Try the default first. It makes a tiny change to one calculation. Later calculations can erase the change, so MLVM tries another place until the finished runs differ.

    How the check works

    Find the difference. Check the calculation.

    A model run is a long sequence of tiny operations, such as multiplying two numbers or reading a value from memory. MLVM can summarize everything the program holds after any operation in a short code. If the recorded values change, the code changes too.

    1. 1

      Start with the same model and input

      Both runs load the same program, model weights and prompt. If they finish with different codes, they held different values, even if they printed the same words.

    2. 2

      Compare the halfway point

      Ask each run for its code halfway through. If the codes match, the difference came later; if they differ, it came earlier. Keep halving until one operation remains.

    3. 3

      Redo that one operation

      Using values saved just before it ran, a separate checker calculates what that operation should have produced. It does not need to rerun the whole model.

    A larger example

    The same words can hide a wrong calculation.

    We made one multiplication slightly wrong during a SmolLM2 language-model run. It printed the same text, but held a different number inside. The run performed 14.8 billion operations; MLVM found and checked the faulty one after 34 comparisons. Open the saved example to see the check yourself.
